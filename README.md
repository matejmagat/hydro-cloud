## Pokretanje backenda

1. Upali Docker (Docker Desktop).

2. Pokreni bazu: U root mapi projekta pokreni naredbu docker-compose up -d (koristi se compose.yml).

3. Pokreni aplikaciju: Run HydroServiceApplication iz service modula.
